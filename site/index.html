La idea sencilla

¿Qué es SHIELD-DNS?

Se instala una vez en una Raspberry Pi o un PC Linux y protege los dispositivos de toda la casa.

Toda la casa protegida

Móviles, teles, consolas y ordenadores, sin instalar nada en cada aparato.

DNS independiente

Pi-hole v6 filtra y Unbound resuelve por su cuenta con DNSSEC, sin depender de Google ni del operador.

Lo puedes ver

El panel de Pi-hole enseña consultas, bloqueos y estadísticas para entender qué ocurre.

Gratis y autoalojado

El código tiene licencia MIT y tus datos se quedan en tu propia máquina.

Sin magia negra

Instalar, paso a paso

Los valores son ejemplos de una red ficticia: 192.168.1.50 es la máquina y 192.168.1.1 el router.

01

Comprueba los requisitos

Raspberry Pi 4/5 de 64 bits o PC Linux con Docker, puerto 53 libre e IP fija en casa. Ejemplo: 192.168.1.50.

02

Prepara la máquina

sudo apt update && sudo apt install -y git openssl
03

Clona e instala

mkdir -p ~/homelab && cd ~/homelab
git clone https://github.com/BertMarti/SHIELD-DNS.git
cd SHIELD-DNS
./install.sh
04

Abre el panel

Visita https://192.168.1.50:8443/admin, acepta el aviso del certificado propio y consulta la contraseña con:

grep PIHOLE_PASSWORD .env
05

Ponlo como DNS

En el router, dentro de DHCP/LAN, usa 192.168.1.50 como DNS. No pongas un DNS secundario externo, porque permitiría saltarse el bloqueo. También puedes configurarlo en un dispositivo concreto.

06

Comprueba que funciona

nslookup doubleclick.net 192.168.1.50
nslookup example.com 192.168.1.50

La primera consulta debe dar 0.0.0.0 y la segunda una IP normal. Nunca abras el puerto 53 ni el panel en el router.

El día a día

Usar SHIELD-DNS

El panel te permite observar y corregir el bloqueo sin tocar cada dispositivo.

Ver lo que ocurre

Abre Dashboard o Query Log para ver consultas y bloqueos.

Permitir un dominio

Si algo se rompe, busca su consulta en Query Log y elige permitir.

Pausar un rato

En el panel puedes desactivar el bloqueo indefinidamente, 10 segundos, 30 segundos, 5 minutos o un tiempo personalizado.

Nombres locales

El instalador prepara aria.lan para resolver nombres dentro de casa.

El bloqueo por DNS no quita todos los anuncios: algunos anuncios de vídeo comparten dominio con el contenido. El DNS privado del móvil o un DNS IPv6 del operador también pueden saltárselo.

Todo en un mismo lugar

SHIELD-DNS con ARIA y HEIMDALL

ARIA convierte el filtro en una pieza fácil de consultar y HEIMDALL lo lleva contigo fuera de casa.

¿Qué añade ARIA?

  • Estadísticas en el Centro de control y pausas de 5, 30 o 60 minutos.
  • Preguntas en el chat como «¿cuántos anuncios has bloqueado hoy?» y /bloqueo en Telegram.
  • Resumen diario, informe semanal y aviso si SHIELD-DNS deja de responder.
  • Control parental por dispositivo con servicios y horarios.
  • Es bloqueo DNS: no puede parar un DNS fijado a mano, todo el DNS cifrado ni una VPN.

Cuando algo no encaja

Preguntas frecuentes

El puerto 53 está ocupado

Comprueba qué servicio lo usa con sudo ss -tulpn | grep 53 y detén el servicio que corresponda antes de ejecutar ./install.sh.

La casa se queda sin internet

Revisa los contenedores y sus logs. Mientras lo arreglas, devuelve temporalmente al router el DNS anterior.

No se bloquean anuncios

Confirma que el dispositivo recibe 192.168.1.50, desactiva DNS privado, revisa IPv6 y mira Query Log.

Una web o aplicación deja de funcionar

Busca el dominio en Query Log y permítelo desde el panel solo si confías en él.

He olvidado la contraseña

Está en el archivo .env. Consulta grep PIHOLE_PASSWORD .env.

¿Funciona en Windows?

No es recomendable: exponer DNS a toda la red suele dar problemas con Windows, WSL2 y Docker Desktop.

¿Es gratis?

Sí. Es autoalojado y tiene licencia MIT.

¿Cómo hago copias de seguridad?

Ejecuta ./backup.sh y guarda la copia fuera de la máquina.
