# 🛡️ SHIELD-DNS - Ad Blocker

**Status:** Pre-release
**Version:** 0.1.0

## What is SHIELD-DNS?

SHIELD-DNS is a DNS-level ad blocker integrated with your VPN.

### Features
- 🚫 Blocks ads on all devices
- 🔧 Easy blocklist management
- 📊 Query logging
- 🔐 Privacy-first
- 🆓 Free and open

## Quick Start

```bash
docker-compose up -d
```

## Configuration

Set DNS to your Raspberry Pi IP in your devices.
